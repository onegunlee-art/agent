# AI Company OS V0.5 — 고객 격리 최소판

V0.5는 실제 고객을 받기 전 공개 운영체제 코드와 고객 원문을 물리적으로 분리한다.
고객 정책 원문은 비공개 저장소에, 현재 상태와 결재는 SQLite Event에, 큰 백업과
삭제 인증서는 해시 결속 파일에 둔다.

완료 관문은 고객별 폴더, sparse fail-closed, 토큰·비용 상한, 타 고객 표식 자동
차단, 공개 저장소·lessons·Evidence 요약 비누출, 고객 백업 복원, 삭제 명령과 삭제
증거, 파일럿 체크리스트의 실행 가능한 테스트다. 모든 fixture는 합성이며 실제 고객
자료는 사용하지 않는다.

완전 검수 패키지는 최종 commit의 소스 ZIP, 테스트·manifest·증거 ZIP, 7개 항목
검수 요청서로 고정한다. 독립 PASS와 CEO 승인 전 push·main 병합·실제 고객 투입은
금지한다.
