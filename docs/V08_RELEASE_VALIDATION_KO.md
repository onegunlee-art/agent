## 보존한 실패와 한계

이전 실험을 성공으로 덮어쓰거나 원본 Evidence를 수정하지 않았다.

1. Codex 앱 업데이트로 예전 절대 실행 파일 경로가 사라져 첫 시도는 프로세스 실행 전에
   실패했다. 현재는 PATH의 native `codex`를 사용하며, 사전 존재 검사를 추가했다.
   과거 Run의 호출 수 1 표기는 원본에 남아 있지만, 당시 미실행 사실을 별도 Event로 남겼다.
2. 기존 시험 변경 금지와 검수자의 회귀 시험 추가 요구가 충돌해 16,379토큰의 NO_CHANGES가
   있었다. 미리 선언한 새 시험 파일만 추가 가능하게 했고 기존 기대값은 보호했다.
3. 다음 시도는 292,575토큰으로 기존 250,000 상한을 초과했다. 파일 변경은 보존하되
   채택하지 않았다. 이후 **새 합성 WorkOrder**에 CEO 최대 운영 지시를 기록하고 시험했다.
4. 앞선 커널 검수 원문 PASS는 SOURCE_CHANGED로 채택 거부됐다. 그 결과를 공식 PASS로
   수동 적재하지 않았다. 당시 원인 진단이 충분하지 않아 원인은 확정하지 않았다.
   변경 경로/오류 진단을 추가하고, 최종 커밋을 동결한 새 검수에서 결속 PASS를 받았다.

  모든 후속 기록을 동일한 자동화 fence의 원자적 작업이라고 표현하지 않는다.
