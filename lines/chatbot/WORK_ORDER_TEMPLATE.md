# 챗봇 생산 WorkOrder 템플릿

## 목표

고객 입력 규격의 공개 사실만 사용하는 로컬 FAQ 챗봇 납품 후보를 만든다.

## 범위

- 고객 폴더 한 곳
- 제품 파일 한 개
- 실패 수용 테스트 한 개
- 기존 전체 평가 재실행

## 완료 기준

- 수용 테스트와 기존 평가가 모두 통과한다.
- 자료 밖 질문, 가격 미상, 비밀정보, 타 고객 표식, 부정 질문을 평가한다.
- Run의 지시문·sparse 패턴·executor diff가 실행 시점 Evidence로 남는다.
- 납품 체크리스트와 해시 보고서가 생성된다.

## 허용

합성 고객 자료, 로컬 브랜치, 로컬 커밋, 승인된 실제 모델 실행 1회.

## 금지

실제 고객 자료, 외부 발송, 평가 기대값 완화, 다른 고객 폴더 열람, 승인 없는 승격.
