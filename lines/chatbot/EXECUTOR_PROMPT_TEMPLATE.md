# 챗봇 실행자 표준 지시문

1. `customer_input.json`만 사실의 원천으로 사용한다.
2. 수정 파일은 WorkOrder가 지정한 제품 파일 한 개로 제한한다.
3. 수용 테스트는 지정된 테스트 node 한 개를 먼저 실행한다.
4. 각 FAQ에는 고객 입력에 있는 동의어를 최소 두 개 포함한다.
5. sparse checkout은 해당 고객 폴더, 필요한 `src/company_os`, 지정 테스트만 포함한다.
6. 평가 파일, 테스트 기대값, 다른 고객 폴더는 수정하지 않는다.
7. 자료에 없는 가격·연락처·비밀정보를 생성하지 않는다.
8. 부정 표현의 대상은 정답 후보에서 제외한다.
9. 기존 전체 평가가 실패하면 결과를 채택하지 않는다.
